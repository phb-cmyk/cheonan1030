# 천안시 웰니스 | 인터랙티브 웹 프레젠테이션

첨부된 **천안시 웰니스 전략발표 10장** PPTX를 기반으로 제작한 정적 웹사이트입니다.

## 실행

압축 파일을 풀고 **`index.html`을 더블클릭**하면 브라우저에서 실행됩니다. 별도 서버, 계정, 데이터베이스, CDN이 필요하지 않습니다.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 생성합니다. (예: `cheonan-wellness`)
2. 이 압축 파일 안의 **모든 파일과 `assets` 폴더**를 저장소의 최상위에 그대로 업로드합니다.
3. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 정해 **Save**를 클릭합니다.
5. 게시되면 `https://<계정>.github.io/cheonan-wellness/`에서 웹사이트를 열 수 있습니다.

웹사이트는 상대 경로(`assets/...`)만 사용하므로 GitHub Pages의 하위 경로에서도 정상 표시됩니다.

## 사용법

- 화면 위 메뉴: 원하는 슬라이드로 이동
- **이전 / 다음**: 장 전환
- **← / →**, **PageUp / PageDown**: 키보드 장 전환
- **O**: 전체 슬라이드 썸네일 열기
- **N**: 발표자 노트 및 원문/출처 열기
- **F**: 슬라이드 전체 화면
- 슬라이드의 그림·카드를 클릭하거나 하단 핵심 포인트 카드를 클릭: 해당 내용 자세히 보기
- 슬라이드 화면에서 마우스 휠, 모바일 화면에서 좌우 스와이프: 장 전환
- **확대**: 모바일에서도 슬라이드 크게 보고 이동 (확대/축소 및 드래그)

## 파일 구조

```
index.html         웹페이지 구조
style.css          디자인·모바일 반응형·애니메이션
app.js             슬라이드 탐색·인터랙션·차트·팝업·확대 기능
slides-data.js     원본 PPTX에서 추출한 전체 텍스트·발표자 노트·출처 및 인터랙션 데이터
assets/            원본 고해상도 슬라이드 10장과 파비콘
```

## 사실관계 및 저작물 관련 안내

- **원본 PPTX의 슬라이드 10장 내용을 고해상도 WebP 이미지로 그대로 포함**하여 레이아웃·글자·차트·일러스트를 최대한 보존했습니다. 이 웹사이트의 그림 자체가 편집 가능한 벡터 도형으로 변환된 것은 아닙니다.
- 발표자 노트, 원본 텍스트, 자료별 출처 링크는 원본 PPTX에 수록된 내용을 옮겼습니다.
- 2026년 방문객 99.2만 명은 원본에서 **잠정치**, 2026년 11월 걷기 챌린지의 수치들은 **계획**, 2027년 전략 로드맵은 **제안·미확정**으로 구분합니다.
- 원본의 서술·수치는 2026-10-30 기준으로 재사용되었으며, **별도 최신 검증을 수행하거나 임의의 통계를 추가하지 않았습니다**.
- 원본에 포함된 이미지·일러스트 및 자료를 외부에 공개할 권한이 있는지 게시 전에 확인하시기 바랍니다.
